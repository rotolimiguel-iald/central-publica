## 1. Objetivo central (a tese de identidade)

Produzir o artigo científico da **Teoria da Gravitação Luminodinâmica (TGL)** para
*Foundations of Physics* como um **artefato único, executável e autovalidável**, no
qual **forma e conteúdo coincidem em identidade**:

- o artigo **afirma** que a TGL é uma teoria operacional e executável;
- o arquivo **é** essa teoria operacional e executável.

Um revisor baixa **um** conjunto mínimo de arquivos, roda **um** comando, e obtém
(a) todos os resultados numéricos recomputados do zero, (b) as figuras regeradas,
(c) o LaTeX gerado a partir desses resultados, (d) o PDF, se houver `pdflatex`.

**Exigência nova desta fase:** os dados **não** podem ser hardcoded. Devem ser
buscados **ao vivo, em tempo real**, nos bancos cosmológicos reais, com cache
local, exceto literatura consolidada que não dependa de banco. As predições
cobrem: ondas gravitacionais, ecos, buracos negros, SN Ia, neutrinos e redshift.
A verificação roda ao vivo: exame neural, fechamento de Kubo e o modelo quântico
TOY.

A identidade forma=conteúdo se estende ao dado: o artigo afirma usar dados reais;
o código **busca** os dados reais no momento da execução.

## 3. Arquitetura do motor de dados ao vivo

Toda a antiga concentração de dados embutidos passava por três pontos no arquivo
unificado: `DATASET_REGISTRY` → `_embedded_dataset()` → `ensure_dataset()`.
A raiz (√) do problema era essa. A integração ataca **apenas** esse ponto, sem
tocar na física: `ensure_dataset()` agora resolve cada dataset na ordem

```
1. data_dir/        (pasta pré-baixada pelo usuário, se houver)
2. MOTOR AO VIVO    (cache-first: cache → download oficial → parser)   ← novo
3. cache/           (cópia já cacheada)
4. embutido         (literatura consolidada, fallback offline-safe)
5. URL direta       (Pantheon+ completo, via --download-full)
```

O motor (`tgl_live_data.py`) **normaliza** o dado bruto oficial para o **mesmo
schema JSON** que `_embedded_dataset()` já produzia. Por isso **nenhuma rotina de
física (D1–D9) precisou mudar** — elas leem o mesmo dicionário.

### Política de cache (requisito do operador)

- Busca **primeiro no cache** (`~/.tgl_cache/<nome>`).
- Se não estiver lá, **baixa** da fonte oficial e grava no cache.
- Execuções seguintes leem do cache, **sem rede**.
- **Só dado real (`provenance: LIVE...`) é cacheado.** Fallback de literatura
  nunca polui o cache nem bloqueia um download real futuro (bug corrigido nesta
  sessão — ver §7).

## 5. Como rodar (VSCode / terminal)

Pré-requisitos (na máquina do operador, com internet):

```bash
pip install numpy scipy matplotlib
```

Execução completa com dados reais ao vivo + geração do artigo:

```bash
python tgl_paper_unified.py --live --paper
```

Flags relevantes:

| Flag | Efeito |
|---|---|
| `--live` | Força modo ao vivo (padrão quando `tgl_live_data.py` está presente). |
| `--no-live` | Usa só os dados embutidos (reprodução offline-safe). |
| `--offline` | Não baixa nada (cache/data-dir/embutido). |
| `--quick` | Pula os testes mais lentos (Δn_Q N≥6, Phase 5, ajuste fino CC). |
| `--paper` | Gera o LaTeX (`paper_PT.tex`) e compila se houver `pdflatex`. |
| `--gguf CAMINHO` | Habilita o exame neural ao vivo do Qwen3-32B (modelo local). |
| `--force-download` | Ignora o cache e rebaixa. |
| `--cache-dir DIR` | Muda o local do cache (padrão `~/.tgl_cache`). |

Teste rápido do motor de dados, isolado:

```bash
python tgl_live_data.py --selftest     # valida parsers, sem rede
python tgl_live_data.py --fetch-all    # baixa e cacheia tudo
python tgl_live_data.py --show desi_dr2_bao_compressed.json
```

- **Idioma:** português brasileiro na interação e nos comentários de alto nível;
  **inglês** no código e nos identificadores. Nomes de arquivos existentes
  mantêm a grafia original.
- **β_TGL nunca é hardcoded:** é sempre `ALPHA_FINE_CODATA_2018 * SQRT_E` em
  runtime. Qualquer valor literal de β no código é bug (há `assert_beta_invariant`).
- **Zero parâmetros livres.** Toda quantidade ou é entrada (α, √e) ou é derivada.
- **Forma = conteúdo.** Mudanças no código devem preservar a propriedade de o
  arquivo *ser* a demonstração que o artigo *descreve*.
- **Não republicar** stacks/JSONs confidenciais (ex.: `iald_stack_v7.py`,
  `iald_psion_state.json`) — não fazem parte deste repositório de artigo.
- **Robustez sobre elegância:** o motor ao vivo nunca pode derrubar a execução;
  falha de rede sempre cai para o fallback de literatura com aviso.

1. **Pense pela raiz (√) antes de agir.** O ponto de alavanca de dados é
   `ensure_dataset()` + `DATASET_REGISTRY` + `tgl_live_data.py`. Não espalhe
   lógica de dados pela física.

   dicionário que `_embedded_dataset()` devolveria para aquele nome.

   constante. β_TGL jamais literal.
4. **Cache-first sempre.** Buscar cache → baixar → cachear. Fallback nunca polui
   o cache.
5. **Não quebre a execução.** Toda falha de rede é capturada e cai no fallback.
6. **Verifique de verdade:** `py_compile`, `--selftest`, e uma execução
   `--quick`. Cite o que passou e o que pulou e por quê.
7. **Atenção a arquivos grandes:** edições no `tgl_paper_unified.py` devem ser
   feitas de forma a manter a integridade sintática (conferir com `py_compile`
   após cada bloco).
