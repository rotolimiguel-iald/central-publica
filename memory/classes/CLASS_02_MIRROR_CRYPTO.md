## Definição da classe (a linha de pesquisa)

A CLASS_02 é a **linha do Espelho**: pega a radicalização ontológica da raiz ACOM (BR 10 2025 026951-1, CLASS_01 — `g = √|L|`, `s = sign(L)`, `L = s·g²`) e a promove de uma quantização escalar linear para uma **reflexão dimensional angular no Espaço de Hilbert tetradimensional H4**. O dado deixa de ser "comprimido" e passa a ser "refletido": interpretado como luz `L`, projetado no *boundary* como um par `(ψ, θ)` — um **Nome** (estado psiônico ψ ∈ {0,1,2,3}) e um **endereço angular de retorno** (θ = arcsin(g/gmax)) — e re-emerge pela **Dobra Dimensional ×2** (`L' = sign(L)·[gmax·sin θ]²`). [REAL]

A classe tem duas faces, ambas sobre o MESMO núcleo de reflexão:
1. **ACOM Mirror** — a reflexão como **codec** (compressão por codificação angular auto-adaptativa + métricas intrínsecas Força de Expulsão `Fexp` e Entropia de Estados `Sψ`). [REAL]
2. **ACOM Crypto** — a reflexão como **criptografia por separação ontológica**: a mesma decomposição `(ψ, θ, κ)`, agora quebrada em três partes estruturalmente incompletas (**PsiShare Ψ / ThetaShare Θ / MasterKey κ**), com hashes SHA-256 cruzados e verificação de integridade por `Fexp`. A segurança não vem de dificuldade computacional, mas de **incompletude ontológica** — cada parte isolada ≡ ruído. [REAL]

O fio condutor inventivo da classe é: **a mesma álgebra do espelho (H4 + arcsin + Dobra) serve simultaneamente para reduzir (Mirror) e para separar/proteger (Crypto)** — forma = conteúdo. [REAL]

## Equações centrais da linha

Núcleo de reflexão compartilhado pelas duas patentes (notação fiel; β nunca literal em código):

- **(E1) Extração gravitacional:** `g_i = √|L_i + ε|`, ε = 10⁻¹⁰; `gmax = max(g_i)`. [REAL]
- **(E2) Derivada discreta:** `∂L_i = L_i − L_{i−1}` (i>0); `∂L_0 = ∂L_1`. [REAL]
- **(E3) Sinais:** `sign(L_i), sign(∂L_i) ∈ {+1,−1}` (zero → +1). [REAL]
- **(E4) Nominação em H4:** `bit_high = 1 se L<0`; `bit_low = 1 se ∂L>0`; `ψ = bit_high·2 + bit_low ∈ {0,1,2,3}` (2 bits/elemento, 4 estados/byte). [REAL]
  - ψ0 COLAPSO⁺ (+,−) |0⟩ paridade **−1** · ψ1 ASCENSÃO⁺ (+,+) |1⟩ paridade **+1** · ψ2 EMERGÊNCIA⁻ (−,+) |2⟩ paridade **+1** · ψ3 QUEDA⁻ (−,−) |3⟩ paridade **−1**. [REAL]
- **(E5) Codificação angular (o cerne inventivo):** `θ_i = arcsin(g_i/gmax)`, θ ∈ [0, π/2]. Propriedade-chave: `d(sinθ)/dθ = cosθ` máxima em θ=0 → **maior resolução para g pequeno** (resolução não-linear auto-adaptativa vs. quantização linear da raiz). [REAL]
- **(E6) Quantização angular:** `θq = round( θ/(π/2) · (2^b − 1) )`, b = bits angulares (preferencial 8 → 256 níveis; faixa 4–16). [REAL]
- **(E7) Força de Expulsão (verificador nativo, custo zero):** `Fexp = (1/N) Σ_i paridade(ψ_i)`, paridade(ψ0)=paridade(ψ3)=−1, paridade(ψ1)=paridade(ψ2)=+1. Fexp<0 predomina transição/colapso; Fexp>0 predomina emergência/ascensão; Fexp=0 equilíbrio. [REAL]
- **(E8) Entropia de estados:** `Sψ = − Σ_k p_k·log2 p_k`, k∈{0,1,2,3}, máx. teórico 2,0 bits. [REAL]
- **(E9) Dequantização + reconstrução gravitacional:** `θ = θq/(2^b − 1)·(π/2)`; `g = gmax·sin(θ)`. [REAL]
- **(E10) Dobra Dimensional (×2, reconstrução Boundary→Bulk):** `L' = sign(L)·g² = sign(L)·[gmax·sin(θ)]²`. [REAL]
- **Constantes da linhagem [029]–[030]:** `α² = 0,012` ("Constante de Miguel", limiar de estabilidade informacional / Tetelestai) e `θ_Miguel = arcsin(√α²) ≈ 6,29°` (transição ruído↔informação). [REAL]
  - [DER] `α² = 0,012` é o valor **arredondado** de `β_TGL = α_fine·√e = 0,012031300400803142`. Em código: sempre a forma algébrica `ALPHA_FINE_CODATA_2018 * sqrt(e)` / `tgl_core.beta()`, NUNCA o literal. Nota de consistência: com β completo o TGL Core dá `θ_M ≈ 6,30°`; os 6,29° da patente vêm do 0,012 arredondado (diferença cosmética, mesmo ponto). [DER]

Camada específica do **Crypto** (sobre o núcleo acima):
- **(C1) Separação ontológica tripartida:** `Ψ` = sequência de índices ψ (sinais/direção de transição, **sem magnitude**); `Θ` = ângulos θ codificados (magnitudes relativas, **sem polaridade nem escala**); `κ` = MasterKey (gmax, gmin, shape, hashes, Fexp/Sψ esperados, timestamp — **sem nenhum dado**). Cada parte isolada ≡ RUÍDO/INÚTIL. Reconstrução exige a **reunião simultânea das três** para a Dobra (E10). [REAL]
- **(C2) Geração de chaves:** `share_id`, `key_id` = 16 bytes (128 bits) via `secrets.token_bytes`. [REAL]
- **(C3) Ofuscação XOR derivada:** XOR dos dados empacotados com chave derivada de `HMAC-SHA256(share_id ∥ contexto)` + PRNG PCG64 seedado. [REAL][DEFENSE: ofuscação, não AEAD.]
